Desktop work teaches a particular kind of patience. The program sits on someone else’s computer. When it fails, you do not get to refresh a website and call it fixed. You learn to read the code, keep state understandable, and change less than you first wanted to.

That is the part I am carrying into the web. Electron is the bridge I am using between a native shell and web technology. I am also learning how to use AI while I do this. It is useful for explaining an unfamiliar API and for a first draft. I still read what I keep. Private product code stays out of the prompt.

This site is the public notebook for that stretch of the career: the work, the skills, the notes, and a resume you can print.
